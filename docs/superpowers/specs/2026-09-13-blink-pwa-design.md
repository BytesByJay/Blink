# Blink PWA (Web Target) — Design Spec

**Date:** 2026-09-13
**Author:** Dhananjay Haridas
**Status:** Approved

## 1. Purpose

Ship Blink as an installable Progressive Web App for **desktop and laptop browsers**, built from the existing Flutter codebase and hosted for free on GitHub Pages.

## 2. Goals & Non-Goals

**Goals:**
- Same Home / Settings / Look-Away experience in Chrome, Edge, Firefox and Safari on desktop.
- Reminders fire while Blink is open in a tab or installed window, including when it is in the background.
- Installable ("Install Blink") with proper icons and manifest.
- Automatic deploy to `https://bytesbyjay.github.io/Blink/` on every push to `main`.
- Zero behaviour change on iOS and Android.

**Non-Goals:**
- iPhone/iPad PWA reminders. iOS suspends backgrounded web apps; reliable delivery would need Web Push plus a backend.
- Reminders when the tab or window is closed (same reason).
- Offline service worker. Flutter's service worker is deprecated; the browser HTTP cache is enough.
- Android Chrome as a target (page-level `new Notification()` is unsupported there).

## 3. Architecture

```
lib/services/
  notification_service.dart   Notifier interface + mobile NotificationService (unchanged behaviour)
  notifier_factory.dart       createNotifier(): conditional import picks mobile or web
  notifier_factory_mobile.dart
  notifier_factory_web.dart
  reminder_timer.dart         Pure Dart one-shot timer with onFired stream (VM-testable)
  web_notifier.dart           Notifier for browsers: ReminderTimer + Notification API + alarm sound
```

- `Notifier` gains `Stream<void> get onFired`. The mobile implementation returns an empty stream.
- `web_notifier.dart` is the only file importing `package:web`; it is compiled only into the web build.

## 4. Reminder Flow (web)

1. **Start** → `scheduleAt(now + interval)` → `ReminderTimer` arms a single `Timer`.
2. Timer fires → `onFired` emits → `SessionService.onReminderFired()` schedules the next reminder.
3. If sound is on, `alarm.mp3` plays.
4. If the page is visible, `onTap` emits immediately and the Look-Away screen opens.
5. If the page is hidden and permission is granted, a browser notification is shown. Clicking it focuses the window and emits `onTap` → Look-Away.

`main.dart` listens to both `onFired` and `onTap`, and both call `onReminderFired()`. A guard in `SessionService.onReminderFired()` ignores the call when the next reminder is still more than 5 seconds away, so one reminder never schedules twice.

## 5. UI Changes (web only, via `kIsWeb`)

- **Permission:** not requested on page load, because Firefox and Safari require a user gesture. It is requested on the Start click. The same click unlocks audio playback.
- **Denied banner:** "Browser notifications are blocked. Reminders only appear while Blink is visible. Allow notifications in your browser's site settings."
- **Vibration switch** hidden.
- **Layout:** Home and Settings content capped at 480 px wide and centred (applied on all platforms; no effect on phones, tablets get the same centred column). Look-Away stays full-window.

## 6. PWA Shell

- `web/` generated by `flutter create --platforms=web`.
- `manifest.json`: name/short_name "Blink", `display: standalone`, `theme_color` teal `#009688`, `background_color` `#0B1220`.
- Icons generated from `assets/img/Blink Logo.png`: favicon, 192/512 (transparent corners) and maskable 192/512 (full-bleed `#0B1220`, artwork in the safe zone).

## 7. Deployment

- `.github/workflows/deploy-web.yml`: on push to `main` → `flutter test` → `flutter build web --release --base-href /Blink/` → `actions/upload-pages-artifact` → `actions/deploy-pages`.
- One-time manual step: repo **Settings → Pages → Source: GitHub Actions**.

## 8. Testing

- **Unit:** `ReminderTimer` (fires at the target time, cancel, reschedule replaces, past time fires immediately) using `fake_async`.
- **Unit:** `SessionService` guard (duplicate fire + tap schedules once). Existing tests unchanged.
- **Build:** `flutter analyze`, `flutter test`, `flutter build web --base-href /Blink/`.
- **Manual (desktop browser):** Start prompts for permission; reminder in a visible tab opens Look-Away; reminder in a background tab shows a notification, and clicking it opens Look-Away; Stop cancels; install prompt appears.

## 9. Known Limits (documented in README)

- Closing the tab or window stops reminders.
- A background tab may deliver a reminder up to about a minute late (browser timer throttling).
- A sleeping laptop fires the reminder on wake.
- OS Focus / Do Not Disturb modes hide browser notifications.
- `alarm.mp3` and `chime.mp3` are still empty placeholders on every platform.

## 10. Known Issue Outside This Spec

On iOS and Android, `onReminderFired()` only runs when the user taps a notification. An ignored reminder stops the loop, contradicting §8.2 of the v1 spec. To be fixed separately.
